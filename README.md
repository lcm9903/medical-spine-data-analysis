# J의료기관 척추 질환 데이터 분석 프로젝트

AI 헬스케어 7기 개별 미션 1차 — 이채민

## 프로젝트 개요
J의료기관에서 제공한 척추(요추) 질환 환자 데이터를 이용해 두 가지 분석/모델링을 수행한다.

1. **정형 데이터 분석**: 환자 기본 정보 + 진단/수술 정보를 통합하여 통계 분석 및 수술실패 예측 모델을 구성한다.
2. **영상 데이터 분석**: 요추 MRI Middle Slice 이미지를 이용해 추간공(척추관) 협착 발병 여부를 분류하는 모델을 전통적 머신러닝과 CNN 두 방식으로 각각 구성·비교한다.

## 사용 데이터
| 파일명 | 설명 |
|---|---|
| `02_Patient_Data.csv` | 환자 기본 정보 (성별, 연령, 신체계측, 통증 지표 등) |
| `02_Patient_Diagnosis.csv` | 진단/수술 정보 (직업, 질병력, 수술기법, 수술실패/재발 여부 등) |
| `02_Disc_image.csv` | MRI Middle Slice 이미지 경로 및 협착 판독 등급(label) |
| `images/` | `02_Disc_image.csv`의 `image_path`가 가리키는 실제 MRI 이미지 폴더 |

> 이미지 파트를 실행하려면 노트북과 같은 경로(또는 `DATA_DIR`)에 `images/` 폴더가 실제로 존재해야 한다.

## 분석/모델링 단계

### 1부. 정형 데이터 분석
1. **데이터 통합 및 결측치 보정**: 환자ID 기준으로 두 테이블 병합, 연령/헤모글로빈수치는 중앙값, 직업은 '미상', 가족력·수술기법은 최빈값으로 대체
2. **문제 1 — 성별 그룹 비교**: 통증기간(월), 헤모글로빈수치에 대해 정규성(Shapiro-Wilk)·등분산성(Levene) 검정 후 t-검정 또는 Mann-Whitney U 검정 수행
3. **문제 2 — BMI 계산**: `체중(kg) / 신장(m)²`
4. **문제 3 — 직업 분포**: 최다 직업군 및 해당 직업군의 성비 산출
5. **문제 4 — 성공 후 재발군 특성**: 수술 성공(`수술실패여부==0`) & 재발(`재발여부==1`) 환자의 평균 연령, BMI, 성비, 직업 빈도 분석
6. **문제 5 — 상관성 검정**: 통증기간과 통증정도 간 Pearson/Spearman 상관분석
7. **문제 6 — 수술실패 예측 모델**: 신체정보+직업+질병력을 특성으로 사용, 결측 보정·원핫인코딩·표준화 파이프라인 구성, 클래스 불균형(실패 15명/성공 201명) 보정을 위해 `class_weight='balanced'` 적용, LogisticRegression/RandomForest/GradientBoosting/SVM 비교 후 F1-score 기준 최적 모델 선정 → `02_best_model.sav` 저장

### 2부. MRI 영상 기반 추간공 협착 분류
1. 이미지 로드 및 320×320 리사이즈, 0~1 정규화
2. **전통적 ML**: 이미지를 flatten 후 PCA(100차원)로 차원 축소, RandomForest/SVM(RBF) 비교
3. **CNN(Keras)**: Conv2D-BatchNorm-MaxPooling 블록 3단 구성, `class_weight`로 불균형 보정, EarlyStopping 적용 → `02_cnn_model.h5` 저장
4. 두 접근법의 Accuracy/F1-score/ROC-AUC 비교 시각화

## 산출물
- `02_best_model.sav` : 수술실패 예측 최적 분류 모델
- `02_cnn_model.h5` : 협착 발병 분류 CNN 모델
- 각 단계별 시각화(박스플롯, 히스토그램, 혼동행렬, 성능 비교 막대그래프)

## 결론 요약
- 정형 데이터에서 성별 간 통증기간/헤모글로빈수치 차이, BMI 분포, 직업별 성비, 재발군 특성, 통증기간-통증정도 상관성을 확인
- 수술실패 예측 모델은 클래스 불균형을 고려한 분류기로 구성
- 협착 분류는 CNN이 일반적으로 공간적 특징 보존 측면에서 유리한 경향이 있으나, 실제 성능은 실행 결과 비교표 기준으로 판단 필요
